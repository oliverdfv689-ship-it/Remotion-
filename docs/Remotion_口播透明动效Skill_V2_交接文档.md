# Remotion 口播透明动效 Skill V2 交接文档

生成日期：2026-06-07

用途：新窗口拿到本文档和 `generate-talking-head-remotion-overlay` Skill 后，可以继续制作同类口播视频透明动效层。

## 1. 这套 Skill 现在解决什么问题

它不是单纯让 Remotion 做一些科技感动画，而是让 Codex 按口播内容做一套“信息导演系统”：

- SRT 负责驱动时间轴，不直接显示字幕。
- 大标题负责抓注意力。
- 词条负责帮助观众理解当前句子。
- 真实 Logo、证据截图、真实图片负责增强可信度。
- 数字图表负责强化记忆点。
- 流程图和 checklist 只在文案真的讲流程/行动时使用。
- SFX 根据语义变化，不再全程重复同一种声音。
- 最终输出透明 MOV，用于叠加到口播视频上。

## 2. 从最早 Codex 视频到 AI 硬件视频的升级

第一条 Codex 视频主要解决了：

- 4:3 透明 Remotion 包装。
- SRT 驱动动效。
- 三段录屏素材按内容匹配时间轴。
- 毛玻璃、黑白高对比、少量橙色强调。
- 录屏窗口、流程图、标签、音效、透明 MOV 输出。

AI 硬件横版视频进一步升级为：

- `1920x1080` 横版 `16:9`。
- 左侧大标题和词条，右侧证据/图片/Logo/图表。
- 按 SRT 细分语义，不再用一个标题覆盖很长时间。
- 词条按口播节奏错峰进入并延长停留。
- 右侧以证据截图、真实图片、真实 Logo、图表为主，避免重复左侧文字。
- 真实品牌与真实场景素材优先。
- 风险、钱、证据、行动建议、评论互动分别使用不同动效。
- 证据截图采用“全图 -> 关键区域放大 -> 高亮锁定 -> 退出”。
- 最终输出 ProRes 4444 Alpha MOV，并用 ffprobe 验证 alpha 和音频。

## 3. 新窗口必须遵守的制作流程

1. 先读 Skill：`generate-talking-head-remotion-overlay`。
2. 读取用户提供的口播视频、SRT、素材目录、参考视频。
3. 先确认视频比例和尺寸，不要默认 4:3、9:16 或 16:9。
4. 分析参考视频，不要直接写代码。
5. 根据 SRT 拆细文案语义，生成场景计划。
6. 给每个语义点决定视觉角色：大标题、词条、证据、右侧图片、数字图表、流程/checklist。
7. 素材按内容和语义匹配，不按文件名机械排序。
8. 先出关键帧图片。
9. 用户确认后出低清或分段 MP4 预览。
10. 预览通过后再输出透明 MOV。
11. 最终用 ffprobe 验证尺寸、时长、alpha、音频。

## 4. 新窗口还需要用户给风格要求吗

如果用户想沿用这次最终版风格，不需要重新长篇描述风格，只要说：

```text
使用 generate-talking-head-remotion-overlay Skill，风格沿用之前 AI 硬件横版最终版：左侧大标题和词条，右侧以证据/真实图片/品牌 Logo/图表为主，商业实战 + 科技控制台，高冲击但不乱堆元素。
```

但新视频仍然需要给：

- 口播视频
- SRT 字幕
- 素材目录
- 参考视频或截图
- 输出比例和尺寸
- 是否需要透明 MOV
- 是否需要音效
- 最终输出目录

原因：Skill 能记住方法和风格规则，但不能凭空知道新视频内容、素材、比例和具体文案。

## 5. 关键规则

- SRT 是动画时钟。
- 不能一个标题跨 20-30 秒覆盖多个语义。
- 不能在句子还没说到之前显示结论。
- 不能品牌已经讲完了，Logo 还留在后面的无关句子里。
- 词条要按口播节奏错峰出现，并停留 3-6 秒左右。
- 证据截图要在说到证据时出现，不能一直挂着。
- 右侧真实图片要对应当前句子，不要错位到后面的文案。
- 流程图优先级低于标题、词条、证据和真实图片。
- 没有意义的小圆圈、小光标、小图标要删掉或换成语义图标。

## 6. 新窗口可直接使用的提示词

```text
请使用 generate-talking-head-remotion-overlay Skill，帮我给新口播视频生成透明 Remotion 动效层。

风格沿用之前 AI 硬件横版最终版：左侧大标题和词条，右侧以证据截图、真实图片、品牌 Logo、图表为主，商业实战 + 科技控制台，高冲击但不乱堆元素。

要求：
1. 先分析口播视频尺寸、SRT 和素材。
2. 先拆细文案语义时间轴，不要一个标题跨很长时间。
3. 大标题、词条、图标、证据窗口、右侧图片、数字图表、流程图都必须跟口播文案时间轴对应。
4. 词条错峰进入并停留足够时间。
5. 右侧内容不要重复左侧文字，以证据、真实图片、真实 Logo 和图表为主。
6. 重要品牌用真实 Logo，没有真实图标时按语境设计或生成语义图标。
7. 证据截图用“全图 -> 关键区域放大 -> 高亮锁定”的动画。
8. 数字要有滚动、冲击、增长动效。
9. 风险、机会、证据、行动建议、评论互动要有不同动效和音效。
10. 先给关键帧图片，再给分段或低清 MP4 预览，确认后再输出透明 MOV。
```
