# 小白使用说明

## 1. 这个 Skill 是做什么的

它用于让 Codex 自动生成一条透明背景的 Remotion 动效视频。最终视频可以放在口播视频上方，和主播画面叠加使用。

Skill 不会直接替你完成剪映中的最终合成。它负责生成可导入剪映的动效层、预览版和独立音效轨。

## 2. 第一次使用前准备什么

建议先准备一个文件夹，把本次视频素材放在一起：

```text
项目素材/
├─ 口播字幕.srt
├─ 口播视频.mp4
├─ 录屏演示-1.mp4
├─ 录屏演示-2.mp4
├─ 参考视频.mp4
└─ 参考截图.png
```

最低限度需要一份 `.srt` 字幕。为了让版式避开主播，最好同时提供口播视频或一张主播画面截图。

## 3. 在新 Codex 中导入 Skill

1. 下载仓库中的 `dist/generate-talking-head-remotion-overlay.skill.zip`。
2. 新开一个 Codex 对话。
3. 把 ZIP 文件拖入对话框。
4. 发送：

```text
请安装并使用这个 Skill。
```

安装完成后，再上传本次视频素材。

## 4. 第一条正式指令

素材上传后，发送：

```text
请使用 generate-talking-head-remotion-overlay Skill，根据我提供的 SRT、口播视频、录屏素材和参考视频完成透明动效层。

要求：
1. SRT 只用于驱动动效时间轴，不要生成口播字幕。
2. 不要显示网格线，不要显示进度条。
3. 优先保留中间主播区域，提示标签放在左右两侧中间位置；重点标题可以短时间覆盖中间区域。
4. 录屏素材按照内容匹配 SRT，不要按照文件名机械排序。
5. 先分析参考视频和素材，再输出时间轴方案与关键帧预览图。
6. 关键帧确认后再生成 MP4 预览版。
7. 最终输出 1440x1080、4:3、透明背景、可以导入剪映专业版的 MOV，并保留独立 SFX 音轨。
```

## 5. 正确的确认顺序

不要跳过预览，按下面顺序确认：

1. **素材分析**：确认字幕时长、人物位置、录屏内容和参考风格。
2. **时间轴方案**：确认哪些段落需要大标题、流程图、图表、标签和录屏窗口。
3. **关键帧图片**：检查标题有没有压字、标签是否太小、两侧信息是否杂乱。
4. **MP4 预览版**：检查动画速度、字幕同步、录屏清晰度和音效节奏。
5. **透明 MOV**：最后才渲染高清透明版本。

这样做的原因很简单：透明 MOV 体积大、渲染慢。先用小文件确认效果，能省下大量等待时间。

## 6. 如何判断画面是否合格

重点检查：

- 主播没有被普通标签长期遮住。
- 大标题足够醒目，但不会和标签互相压住。
- 小标签字体在手机上仍然看得清。
- 同类标签放在一起，不要拆散到左右两边。
- 流程类内容可以使用透明流程图短暂覆盖主播区域。
- 重要名词使用更大的图标和字体，例如 Codex、Remotion、ChatGPT。
- 真实存在的品牌优先使用真实 Logo。
- 录屏窗口要放大关键区域，避免观众看不清。
- 音效按语境变化，不要每次都用同一个声音。
- 最终透明视频没有黑底、绿幕残边、网格线或进度条。

## 7. 在剪映专业版中使用

1. 新建 `4:3` 项目。
2. 导入口播视频，放到主轨道。
3. 导入 `overlay-alpha.mov`，放到口播视频上方轨道。
4. 导入 `sfx-stem.wav`，检查音量是否压住口播。
5. 透明 MOV 会直接显示动效，不需要色度抠图。

如果电脑加载透明 MOV 比较慢，可以先使用 MP4 预览版完成时间轴确认，最后再替换为 MOV。

## 8. 常见反馈怎么说

你不需要使用专业术语。可以直接告诉 Codex：

```text
大标题再往上移动一点，不要压住下面的标签。
```

```text
同一类标签放在一起，不要拆到左右两边。
```

```text
Codex 是重要名词，请把图标和字体放大，并加一个明显的入场动画。
```

```text
这个录屏窗口看不清，请放大关键区域，并给需要看的位置加高亮框。
```

```text
周活 300 万出现得太早，请按照 SRT 重新检查时间点。
```

## 9. 遇到问题时怎么办

把报错原文发给 Codex，让它先检查：

- Remotion 插件是否可用
- Node.js 和 npm 是否可用
- FFmpeg 与 ffprobe 是否可用
- 浏览器或 Remotion Studio 是否能正常启动
- 输出目录剩余空间是否足够
- 透明 MOV 编码是否包含 Alpha 通道

不要手动反复试错。把问题描述、截图和报错文字一起交给 Codex处理，定位会更快。
